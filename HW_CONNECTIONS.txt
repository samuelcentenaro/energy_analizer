================================================================================
                        CIRCUIT PROTECTION
================================================================================

    1. VOLTAGE DIVIDER (ZMPT101B input)
       ┌───────────┐
       │  ~250V AC │
       │ (mains)   │
       └─────┬─────┘
             │
           ╱R1╲  (High resistor, typically 100kΩ or 220kΩ)
           ╲  ╱
             ├──► (to capacitor → ADC)
             │
           ╱R2╲  (Lower resistor, typically 10kΩ)
           ╲  ╱
             │
            GND

    
    2. BURDEN RESISTOR (SCT013-030 output)
       ┌──────────────────┐
       │ SCT013-030       │
       │ 0-30A AC Input   │
       └────┬────┬────────┘
            │    │ 
            R    C    (18Ω burden + capacitor)
            │    │
            ├────┴──────┬───────► (to bias + ADC)
                        │
                        R        (bias resistor network for 1.65V offset)
                        │
                        ├────► ADC pin (GPIO34)
                        │
                       GND


    3. BROWNOUT PROTECTION (internal ESP32)
       ├─ Automatically resets if Vcc < 2.8V
       ├─ Prevents flash corruption
       └─ Enabled in menuconfig

    4. WATCHDOG TIMER (internal ESP32)
       ├─ 10 second timeout
       ├─ Resets if task blocks scheduler
       └─ Enabled for stability

    5. CAPACITIVE COUPLING (optional on ADC inputs)
       ├─ Block DC offset (especially current sensor)
       ├─ Pass-through AC signal
       └─ Typical: 10µF ceramic capacitor

================================================================================
                        DEVELOPMENT SETUP
================================================================================

    Hardware needed:
    ├─ ESP32 development board (with USB CH340/CP2102)
    ├─ Protoboard or breadboard
    ├─ Jumper wires
    ├─ 4.7kΩ resistors × 2 (I2C pull-ups)
    ├─ 100kΩ + 10kΩ resistors (voltage divider)
    ├─ 18Ω + capacitor burden (current sensor)
    ├─ 220Ω resistor (LED)
    ├─ SSD1306 OLED module (pre-assembled)
    ├─ ZMPT101B voltage sensor module (pre-assembled)
    ├─ SCT013-030 current sensor + burden resistor
    ├─ 3 push buttons
    └─ 1 LED + resistor (status indicator)

    Software needed:
    ├─ ESP-IDF v5.1+
    ├─ VS Code + ESP-IDF extension
    ├─ Compiler: xtensa-esp32-elf-gcc
    └─ Python 3.7+ (for idf.py tools)

    └─ Oscilloscope (optional, for FFT verification)
       └─ Verify 8 kHz ADC sampling visually
